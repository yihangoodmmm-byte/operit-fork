# 排版规范（本轮重写依据）

> 依据 `/sdcard/Vibe coding/skills/finesse-skill` 的 product register：
> `product-ui.md`（surface 与卡片配方）、`mobile-floor.md`（移动端硬底线）、
> `redesign-mode.md`（重做流程：先审计再按杠杆排序）、`anti-cheap.md`（廉价感黑名单）。

## 1. 栅格与节奏

- 基础栅格 **8dp**，只有细线与图标间距允许 1–4dp 的微调。
- 页面左右内边距 **16dp**；列表行内左右 **4dp**（行本身再吃 12dp，视觉对齐 16）。
- 分区之间 **12dp**；分区标题上 12dp、下 4dp。

## 2. 圆角层级（锁定，不再混用）

| 层级 | 值 | 用途 |
|:---|:---|:---|
| chip | 999dp | 状态胶囊 |
| 控件 | 10dp | 按钮、输入框内元素 |
| 面板 | 14dp | 卡片、弹层 |
| 输入框 | 22dp | 底部输入区 |

> 之前 8/9/10/12/14/16/18/22 混用，是"廉价"最直接的来源之一。

## 3. 触控

- 所有可点元素**触控区 ≥ 44dp**（视觉可以更小，用外层 Box 撑开）。
- 发送键：视觉 34dp 圆，触控 44dp。
- 行高：列表项 **≥ 48dp**（有副标题时 52dp）。

## 4. 位置规则（本轮的核心改动）

| 元素 | 位置 | 理由 |
|:---|:---|:---|
| 返回 | **左上角** | 移动端肌肉记忆；只在 `canGoBack` 时出现 |
| 抽屉/侧栏 | **右上角** | 原来在左上角，和返回抢同一个位置，导致"进入/退出"是同一颗按钮 |
| 更多操作 | 右上角（抽屉右侧） | 主次分明 |
| 输入框 | **最贴底边** | 拇指区应该留给最高频的动作 |
| 状态信息（模型/上下文） | **输入框上方** | 原来是下方，既占拇指区，又会被 IME 工具条压住 |
| 空状态 | 垂直居中偏上 | 避免与底部输入栏的重量打架 |

## 5. 表面与分隔

- 不用纯 `#fff`/`#000`；底色是暖纸色（见 `Theme.kt` 的纸纹层）。
- 列表**不用卡片**：行 + 1dp `outlineVariant` 细线（0.6 alpha）。
- 弹层/浮窗用浅填充（主色 7–18% alpha），**不用描边**——描边在深色底上是一圈发亮的线。
- 不使用投影；层次靠色阶和细线。

## 6. 字体

- 中文 **CC Hei**、西文 **CC Inter**（移植自 cccodroid，见 `Type.kt`）。
- 标题 SemiBold，正文 Normal，**字距归零**（标题保留 0.2–0.8sp 的弱对比）。
- 角色名一行只在**段落开头**出现，连续消息不重复。
